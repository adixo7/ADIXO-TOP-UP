---
name: Guild inventory scope
description: Preserve sold guild listings and their controls when clearing active inventory.
---

When asked to remove guilds that are for sale, remove only the active sale listings. Keep already-sold listings and the sorting controls; show an availability notice when no active listings remain.

**Why:** The user clarified that removing all guild inventory also removed sold cards and sorting controls they wanted to keep.

**How to apply:** For guild inventory changes, distinguish active listings from sold records and preserve the existing catalog controls unless the user asks for a full reset.
